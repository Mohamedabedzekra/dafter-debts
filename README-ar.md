# دفتر الديون — مشروع تطبيق أندرويد (APK)

هذا مشروع أندرويد كامل يغلّف تطبيق «دفتر الديون» (يعمل دون إنترنت). لا يحتاج إذن إنترنت أصلًا.

## الطريقة 1: بناء الـ APK مجانًا على GitHub (بدون تثبيت أي برنامج)

1. أنشئ حسابًا مجانيًا على github.com ثم أنشئ مستودعًا جديدًا (New repository) باسم `dafter-debts`.
2. ارفع **كل محتويات هذا المجلد** إلى المستودع (زر Add file ← Upload files).
   - انتبه: يجب أن يُرفع المجلد المخفي `.github` أيضًا. إن لم تستطع رفعه من المتصفح فاستخدم تطبيق GitHub Desktop أو أنشئ الملف يدويًا: Add file ← Create new file واكتب في الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** وانتظر انتهاء «Build APK» (3 إلى 6 دقائق). إن لم يبدأ تلقائيًا اختره واضغط Run workflow.
4. افتح التشغيل الناجح ← في الأسفل قسم **Artifacts** ← حمّل `dafter-debts-apk`. هو ملف zip بداخله `app-debug.apk`.
5. انقل `app-debug.apk` إلى هاتفك وافتحه، واسمح بالتثبيت من مصدر غير معروف عندما يطلب الهاتف ذلك.

## الطريقة 2: بالبناء على جهازك (Android Studio)

افتح هذا المجلد في Android Studio ثم Build ← Build APK(s). الملف يظهر في `app/build/outputs/apk/debug/`.

## ملاحظات

- الـ APK الناتج موقّع بمفتاح التجربة (debug)، وهو يصلح للاستخدام الشخصي. للنشر على Google Play تحتاج نسخة release بمفتاح توقيعك الخاص.
- التطبيق يحفظ بياناته داخل الهاتف. **لا تحذف التطبيق قبل تصدير نسخة احتياطية** (الإعدادات ← تصدير نسخة؛ تُحفظ في مجلد التنزيلات).
- لتعديل التطبيق نفسه عدّل الملف `app/src/main/assets/index.html`.
- أقل إصدار أندرويد مدعوم: 8.0 (API 26).
